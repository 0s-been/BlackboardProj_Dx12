# 확인용 그림 데이터

저장/불러오기 기능을 확인하기 위한 그림입니다.

| 파일 | 내용 |
|---|---|
| `test_drawing.board` | 칠판 프로그램으로 그리고 [저장] 버튼으로 저장한 데이터 (선 6,559개, 점 10,392개, 배경 흰색, 약 241KB) |
| `test_drawing_expected.png` | 위 파일을 불러왔을 때 칠판에 보여야 하는 화면 (창 클라이언트 좌표 x 420~968, y 18~756 부분) |
| `test_drawing_source.png` | 따라 그린 원본 이미지 |

## 만든 방법

1. 원본 이미지를 칠판 위 546×736px 크기로 줄이고 16가지 색으로 줄였습니다.
2. 4px 높이의 가로줄마다 같은 색이 이어지는 구간을 선 하나로 만들었습니다.
3. 프로그램을 실행한 뒤 마우스 자동 조작으로 그렸습니다.
   - 배경을 흰색으로 바꾸고, 휠로 붓 굵기를 5px로 맞췄습니다.
   - 색마다 **사용자 색상**의 R/G/B 칸에 값을 입력했습니다.
   - 그 색의 선들을 드래그로 그렸습니다.
4. [저장] 버튼으로 이 파일을 저장했습니다.

## 확인 방법

- **직접 확인**: 프로그램에서 [불러오기] → `test_drawing.board`를 고릅니다. 상태 표시줄에 `선 개수: 6559`, 배경 `흰색`이 나오고 `test_drawing_expected.png`와 같은 그림이 보이면 정상입니다.
- **단위 테스트**: S01~S03
  - 파일을 불러와 선 개수와 배경을 확인합니다.
  - 다시 저장했을 때 원본 파일과 바이트 단위로 같은지 확인합니다.
- **E2E 테스트**: TC25
  - 실행 중인 프로그램에서 이 파일을 불러옵니다.
  - 화면을 `test_drawing_expected.png`와 픽셀 단위로 비교합니다.
